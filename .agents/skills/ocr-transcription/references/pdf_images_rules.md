# قواعد بروتوكول تحويل صفحات PDF إلى صور (PDF Image Pipeline Rules)

يُستعمل هذا المسار حين يطلب المستخدم صوراً مستقلة للصفحات قبل إدخالها إلى سير المعالجة أو إرسالها لنموذج الرؤية. 

## ١. تعليمات الاستدعاء وأوامر التشغيل

```powershell
python "<Skill_Dir>/scripts/pdf_to_images.py" "pdf/input.pdf"

# صفحات محددة
python "<Skill_Dir>/scripts/pdf_to_images.py" "pdf/input.pdf" --pages "1-3,8"

# معرفة العدد دون إنشاء صور
python "<Skill_Dir>/scripts/pdf_to_images.py" "pdf/input.pdf" --info-only
```

## ٢. ضوابط المعالجة وحفظ الحالة

- **تسمية المخرجات**: يخرج السكربت PNG مستقلاً لكل صفحة، مع ترقيم أصلي ثابت مثل `book_p001.png`.
- **أداة الرسم والدقة القياسية**: يستعمل السكربت مكتبة `PyMuPDF` (المسماة `fitz`) بالدقة القياسية **300 DPI** افتراضياً؛ لكونها أسرع وأدق في تنعيم الرسم البصري وتفاصيل الحروف والضبط العربي مقارنة بالمكتبات الخارجية.
- **جذر التشغيل**: تُحل المسارات الافتراضية من دليل العمل الحالي (`Cwd`)؛ فتقع الصور في `output_images/chunk_N/` والحالة في `output_parts/progress.json` ولو كان ملف PDF خارج مساحة العمل.
- **حالة الاستئناف**: يستأنف السكربت حصراً إذا طابق ملف الحالة المصدر والمسار والدقة ونطاقات الأجزاء المطلوبة. ويرفض الحالة التالفة أو المخالفة دون طمسها.
- **حماية المجلد**: لا يبدأ تشغيل صور جديد في `output_parts/` أو `output_images/` غير فارغين بغير حالة مطابقة؛ ويحافظ على الآثار السابقة حتى ينقلها المستخدم أو ينظفها صراحة.
- **سير المعالجة اللاحقة**: لا تُرسل الصور الناتجة إلى نموذج الذكاء الاصطناعي أو تُستخلص نصوصها آلياً بمجرد تشغيل هذا المسار؛ فهو مخصص لتهيئة الصور فحسب، ومن ثم يتولى الوكيل معالجة الصور وقراءتها وفق القواعد العامة للمهارة.
